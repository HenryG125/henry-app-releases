# PlumbTrack Pro Android Updates

Official verified release channel for PlumbTrack Pro Android.

- The permanent update manifest is stored in `apps/PlumbTrack/`.
- Production-signed APKs are published as GitHub Release assets.
- APK identity, SHA-256, production certificate, and signing lineage are verified before publication.
- Source code, keystores, signing lineage files, passwords, and private data are never stored here.

Current successfully published release: **v3.0.18**
